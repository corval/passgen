# 🔒 Generador Avanzado de Contraseñas Seguras  

**Herramienta de seguridad con cifrado SHA-256 y personalización integral, ¡Moviendo el cursor!**  

Un generador de contraseñas robusto diseñado para crear claves criptográficamente seguras, ideal para proteger cuentas digitales. Combina algoritmos modernos con una interfaz intuitiva para garantizar máxima seguridad y usabilidad.  

## 🛠️ Características Principales  
- **Algoritmo SHA-256**: Generación basada en hashing criptográfico para aleatoriedad impredecible, por movimiento de cursor.
- **Personalización flexible**:  
  - Longitud ajustable (10-20 caracteres) mediante slider interactivo.  
  - Opciones para incluir: mayúsculas, minúsculas, números y símbolos.  
  - Semilla personalizable para generar contraseñas reproducibles.  
- **Interfaz profesional**:  
  - Diseño responsive con CSS moderno (variables personalizadas, animaciones).  
  - Feedback visual: mensajes de estado, spinner de carga y notificaciones.  
- **Funcionalidades extras**:  
  - Copiado automático al portapapeles con validación.  
  - Registro de actividad (IP y timestamp) *[solo con fines demostrativos]*.  

## ⚙️ Tecnologías Utilizadas  
- **Frontend**: HTML5, CSS3 (Flexbox, Variables CSS), JavaScript ES6+  
- **Librerías**: jQuery, Web Crypto API (SHA-256)  
- **APIs**: Geolocalización de IP pública (api.ipify.org)  

## 🎯 Propósito  
Desarrollar una solución de seguridad accesible que:  
1. Eduque sobre principios básicos de criptografía.  
2. Demuestre integración de APIs y algoritmos complejos en interfaces simples.  
3. Priorice buenas prácticas de UX en herramientas técnicas.  

*⚠️ Nota: El registro de contraseñas en el código es una demostración educativa. En entornos reales, nunca se almacenan contraseñas generadas.*
